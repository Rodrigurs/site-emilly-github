# Portfólio — Emilly Victorya

Portfólio pessoal sobre fotografia da fauna amazônica, o sonho de ser militar, jogos online e família.

Feito com **HTML, CSS e JavaScript** (Bootstrap 5).

## Páginas
- `index.html` — portfólio principal
- `alerta-amazonia.html` — página "Amazônia em alerta"

## Como ver no computador
Abra a pasta no VS Code e rode `index.html` com a extensão Live Server.
